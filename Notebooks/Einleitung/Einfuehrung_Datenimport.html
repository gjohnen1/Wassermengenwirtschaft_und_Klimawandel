Ausführen von Code in Jupyter Notebooks#

In Jupyter Notebooks kann Code interaktiv ausgeführt werden. Dies ermöglicht es, den Code schrittweise auszuführen und die Ergebnisse zu überprüfen.

Um Code in einer Zelle auszuführen, gibt es verschiedene Möglichkeiten:

  • Klicken auf den “Run”-Button: In der Symbolleiste oben im Notebook befindet sich ein Button mit einem Pfeilsymbol. Durch Klicken auf diesen Button wird der Code in der aktuellen Zelle ausgeführt. Alternativ kann auch die Tastenkombination “Shift + Enter” verwendet werden, um den Code auszuführen und zur nächsten Zelle zu gelangen.

  • Verwendung der Tastenkombination “Ctrl + Enter”: Falls nur der Code in der aktuellen Zelle ausgeführt werden soll, ohne zur nächsten Zelle zu wechseln, kann die Tastenkombination “Ctrl + Enter” verwendet werden. Dadurch wird der Code ausgeführt, und der Cursor verbleibt in derselben Zelle.

  • Verwendung der Tastenkombination “Shift + Enter”: Falls der Code in der aktuellen Zelle ausgeführt werden soll und direkt zur nächsten Zelle zu gewechselt werden soll, kann die Tastenkombination “Shift + Enter” verwendet werden. Dadurch wird der Code ausgeführt, und zur nächsten Zelle gesprungen.

Es ist wichtig zu beachten, dass der Code in den Zellen in der Reihenfolge ausgeführt wird, in der sie ausgeführt werden. Wenn also Code in einer bestimmten Zelle geändert und erneut ausgeführt wird, werden die Ergebnisse entsprechend aktualisiert.

Das Ausführen von Code in Jupyter Notebooks ermöglicht eine iterative Entwicklung und erleichtert das Experimentieren und die Datenanalyse. Probiert es hier aus, indem Ihr den Code in den Codezellen dieses Notebooks ausführt!

Grundlegende Python-Konzepte#

Python bietet eine Vielzahl von eingebauten Funktionen und Konzepten, die das Programmieren erleichtern. Hier sind einige der wichtigsten Grundlagen:

Variablen und Datentypen#

Variablen dienen dazu, Werte zu speichern. Jeder Wert in Python hat einen bestimmten Datentyp, der bestimmt, welche Art von Daten gespeichert ist und welche Operationen damit durchgeführt werden können. Die wichtigsten einfachen Datentypen sind:

  • int: Ganze Zahlen (z.B. 10, -5, 0)

  • float: Gleitkommazahlen (Dezimalzahlen, z.B. 3.14, -0.5, 1.0)

  • str: Zeichenketten (Text, in Anführungszeichen eingeschlossen, z.B. 'Hallo', "Python")

  • bool: Wahrheitswerte (True oder False)

Mit der Funktion type() können wir den Datentyp einer Variablen überprüfen.

# Eine Variable 'a' mit einem Float-Wert
a = 1.1
print(a)
type(a)

1.1

float

# Eine Variable 'b' mit einem String-Wert
b = "1.1"
print(b)
type(b)

1.1

str

# Eine Variable 'c' mit einem Integer-Wert
c = 1
print(c)
type(c)

1

int

# Eine Variable 'd' mit einem Boolean-Wert
d = True
print(d)
type(d)

True

bool

Umwandlung von Datentypen (Type Casting)#

Manchmal müssen wir den Datentyp einer Variablen ändern. Zum Beispiel, wenn wir eine Zahl, die als Text gespeichert ist (String), in eine tatsächliche Zahl (Integer oder Float) umwandeln wollen, um damit rechnen zu können. Dies nennt man Type Casting.

  • int(): Wandelt in eine ganze Zahl um.

  • float(): Wandelt in eine Gleitkommazahl um.

  • str(): Wandelt in eine Zeichenkette um.

a = int(1.1)
print(a)

1

type(a)

int

float(a)

1.0

str(a)

'1'

Funktionen#

Funktionen sind wiederverwendbare Codeblöcke, die eine bestimmte Aufgabe erfüllen. Sie helfen, Code zu organisieren und Wiederholungen zu vermeiden. Man definiert eine Funktion mit def und kann ihr Argumente (Parameter) übergeben.

def square():
    '''
    Diese Funktion berechnet das Quadrat von 2.
    '''
    return 2 * 2

square()

    '''
    Diese Funktion berechnet das Quadrat einer gegebenen Zahl x.
    
    Parameter:
        x (int oder float): Die Zahl, deren Quadrat berechnet werden soll.
    
    Rückgabewert:
        int oder float: Das Quadrat von x.
    '''
    return x ** 2

square16 = square(16)

square16

256

str(square16)

'256'

square(x=3)

9

def quadrat(zahl):
    return zahl ** 2

quadrat(zahl=3)

Kontrollstrukturen: If-Anweisungen#

Mit If-Anweisungen können wir Code nur dann ausführen, wenn eine bestimmte Bedingung erfüllt (True) ist. Mit else können wir einen alternativen Codeblock definieren, der ausgeführt wird, wenn die Bedingung nicht erfüllt (False) ist.

zahl = -15
if zahl > 0:
    print("Die Zahl ist positiv.")
else:
    print("Die Zahl ist nicht positiv.")

Die Zahl ist nicht positiv.

Eine CSV-Datei einlesen mit Pandas#

Die häufigste Art, tabellarische Daten in Python zu importieren, ist die Verwendung der Funktion pd.read_csv() aus der Pandas-Bibliothek. Diese Funktion benötigt als wichtigstes Argument den Pfad zur CSV-Datei.

Wenn eine Datendatei (nennen wir sie data.csv) im selben Ordner wie diese Notebook-Datei gespeichert ist, können wir sie einfach mit ihrem Namen einlesen: df = pd.read_csv('data.csv')

Hinweis: Oben wird die Funktion read_csv aus der Pandas-Bibliothek (mit der Kurzform pd) aufgerufen. Der Dateipfad ist in diesem Fall einfach 'data.csv'. Beachten Sie, dass der Pfad als Zeichenfolge (String) übergeben wird, d.h. in ‘einfache Anführungszeichen’ oder “doppelte Anführungszeichen” eingeschlossen.

In den meisten Fällen sind Daten jedoch besser organisiert, z.B. in einem separaten “Daten”-Ordner, anstatt direkt neben dem Code oder Notebook. Wenn die Datei woanders gespeichert ist, müssen wir den Pfad dorthin angeben. Wir versuchen nun, die Datei Hidden_Creek_stage_data.csv einzulesen, die sich im Ordner Projekt_Daten befindet.

Möglichkeiten zur Angabe eines Dateipfads#

Um die Datei Hidden_Creek_stage_data.csv aus dem Verzeichnis Projekt_Daten zu laden, haben wir mehrere Möglichkeiten:

  1. Absoluter Pfad: Geben Sie den vollständigen Pfad von der Wurzel des Dateisystems an. Dies ist spezifisch für jeden Computer und jedes Betriebssystem. Beispiel (muss angepasst werden!): 'C:\Users\IhrName\Projekt\Inhalt\Projekt_Daten\Hidden_Creek_stage_data.csv' oder '/home/ihrname/Projekt/Inhalt/Projekt_Daten/Hidden_Creek_stage_data.csv'.     • . steht für das aktuelle Verzeichnis.

Gemäß dem Prinzip Don’t Repeat Yourself ist es zu empfehlen, Variablen zu benutzen um Pfade von Dateien und Ordnern zu speichern. Es kann so vermieden werden, dass Dinge mehrmals geschrieben oder deklariert werden (mehr Eingaben = höhere Wahrscheinlichkeit eines Tippfehlers). Dies sollte grundsätzlich gleich zu Beginn einer Arbeitsdatei geschehen. Es sollten immer leicht verständliche Variablennamen, z. B. data_folder = <some path to data>.

Hinweis: Es empfiehlt sich, leicht verständliche Variablennamen zu verwenden. Wenn beispielsweise eine berechneten Abfluss speichern, die den durchschnittlichen jährlichen Durchfluss darstellt, ist dies gut bei qa und avg_annual_flow_m3s zu erkennen. Ersteres mag in einem Moment Sinn machen, aber ein Jahr später weder für jemand anderen noch für einen selbst. Letzteres ist viel klarer und enthält auch eine Art Kodierung der Einheiten (m3s lässt sich leicht als \(\frac{m^3}{s}\) interpretieren, oder cms = “cubic <>metres pros<>Sekunde”) – Einheiten sind wichtig!!

Erste Dateninspektion und Qualitätschecks#

Nachdem wir die Daten erfolgreich in einen Pandas DataFrame (df) geladen haben, ist der nächste wichtige Schritt, einen ersten Blick darauf zu werfen und grundlegende Qualitätschecks durchzuführen. Pandas bietet dafür sehr nützliche Funktionen:

  • df.head(n): Zeigt die ersten n Zeilen des DataFrames an (Standard ist 5). Nützlich, um die Spaltennamen und die ersten Datenpunkte zu sehen.

  • df.tail(n): Zeigt die letzten n Zeilen an.

  • df.shape: Gibt ein Tupel zurück, das die Anzahl der Zeilen und Spalten angibt (Zeilen, Spalten).

  • df.info(): Gibt eine kompakte Zusammenfassung des DataFrames, einschließlich der Anzahl der Zeilen und Spalten, der Spaltennamen, der Anzahl der Nicht-Null-Werte pro Spalte und der Datentypen (Dtype) jeder Spalte. Sehr wichtig, um fehlende Werte und falsche Datentypen schnell zu erkennen!

  • df.describe(): Berechnet deskriptive Statistiken (Anzahl, Mittelwert, Standardabweichung, Min/Max, Quartile) für numerische Spalten. Hilft, die Verteilung der Daten zu verstehen und Ausreißer zu identifizieren.

  • df.dtypes: Zeigt nur die Datentypen jeder Spalte an.

  • df.isnull().sum(): Zählt die Anzahl der fehlenden Werte (NaN - Not a Number) pro Spalte. Essenziell für die Datenqualität!

print(df.shape)

Der Fehler (TypeError: unsupported operand type(s) for +: 'int' and 'str' oder ähnlich) bestätigt das Problem.

Wenn eine CSV-Datei mit Pandas importiert wird, versucht Pandas automatisch, den Typ jeder Spalte zu erkennen. Wenn eine Spalte jedoch Werte enthält, die nicht eindeutig als Zahlen interpretiert werden können (z.B. Text, gemischte Typen, spezielle Zeichen), weist Pandas ihr oft den allgemeinen object-Typ zu.

Dies ist ein sehr häufiges Problem bei realen Daten! Ein wichtiger Teil der Datenanalyse besteht darin, solche Typ-Probleme zu identifizieren und zu beheben (Datenbereinigung).

Niemals sollten große CSV-Dateien manuell bearbeitet werden, um solche Probleme zu lösen. Wir nutzen Python und Pandas, um dies effizient und reproduzierbar zu tun.

Konvertieren von Datentypen in Pandas#

Da wir mit den Wasserstandsdaten numerische Berechnungen durchführen möchten, müssen wir die Spalte Value in einen numerischen Datentyp umwandeln. Da Wasserstände Dezimalwerte haben können, ist float (Gleitkommazahl) der geeignete Typ.

Pandas bietet dafür die Methode .astype(): df['NeueSpalte'] = df['AlteSpalte'].astype(float)

Es ist gute Praxis, der neuen, konvertierten Spalte einen aussagekräftigeren Namen zu geben, der idealerweise auch die Einheit enthält (wenn bekannt). Wir nennen sie stage_m (für Wasserstand in Metern).

Alternative: Pandas bietet auch die Funktion pd.to_numeric(). Ein Vorteil davon ist die Option errors='coerce', die automatisch alle Werte, die nicht in Zahlen umgewandelt werden können, durch NaN (Not a Number - fehlender Wert) ersetzt. Das kann sehr nützlich sein, um problematische Einträge zu finden. df['stage_m'] = pd.to_numeric(df['Value'], errors='coerce')

Für dieses Beispiel verwenden wir .astype(float). Wenn dies fehlschlägt, wissen wir, dass es nicht-numerische Einträge gibt, die wir untersuchen müssten. Wenn es funktioniert, waren alle Strings als Zahlen interpretierbar.

try:
    # Versuche, die 'Value'-Spalte in float zu konvertieren und in neuer Spalte zu speichern
    df['stage_m'] = df['Value'].astype(float)
    print("Konvertierung zu float erfolgreich.")
    
    # Überprüfe den Datentyp der neuen Spalte
    print(f"Datentyp der neuen Spalte 'stage_m': {df['stage_m'].dtype}")
    
    # Zeige die ersten Werte der neuen Spalte
    print("\nErste Werte der neuen Spalte 'stage_m':")
    display(df[['Value', 'stage_m']].head())
    
except ValueError as e:
    print(f"Fehler bei der Konvertierung (ValueError): {e}")
    print("Dies bedeutet, dass mindestens ein Wert in der Spalte 'Value' nicht direkt in eine Zahl umgewandelt werden kann.")
    print("In diesem Fall wäre pd.to_numeric(df['Value'], errors='coerce') eine gute Alternative.")

Ein LLM könnte daraufhin Code wie diesen vorschlagen:

# Hypothetischer Code von einem LLM (Beispiel)

if isinstance(df.index, pd.DatetimeIndex):
    df_2010 = df[df.index.year == 2010]
    print("Daten für 2010 erfolgreich gefiltert.")
    display(df_2010.head())
    print(f"Anzahl der Einträge in 2010: {len(df_2010)}")
else:
    print("Der Index ist kein DatetimeIndex. Bitte zuerst konvertieren.")
